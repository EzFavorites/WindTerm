# 安全模型

## 凭据

- 长期保存的密码、私钥口令等只进 **保险库**（`crates/term-vault`）。
  保险库用 Argon2 派生密钥并加密，主密码不落盘。
- 会话库（SQLite）只存引用，不存明文密码；测试会检查库文件里不出现明文。
- 会话表单里的密码有三种策略：
  - **不记住**：只在本次连接的生命周期内使用。
  - **本次记住**：只放在进程内存，退出即忘，不需要主密码。
  - **永久记住**：写入保险库，需要主密码解锁。
- 修改主密码时，保险库内容不变，只重新封装；新口令同样通过强度检查。
- 私钥生成器支持 ed25519 / RSA 3072 / ECDSA P-256，可选口令加密；私钥内容
  不回传到界面。

## 主机密钥

- 首次连接采用 TOFU：把服务端指纹记入 `known_hosts`。
- 指纹变化时**阻断连接**，同时显示新旧指纹。不会把它当成「未知主机」自动
  信任——那等于接受中间人。
- 已知主机列表可以逐条「忘记」，之后重新走 TOFU。

## 数据落盘

| 内容 | 位置 | 说明 |
|---|---|---|
| 会话库 | `profile_dir/sessions.db` | SQLite；不含明文密码 |
| 保险库 | `profile_dir/vault.*` | Argon2 加密 |
| 偏好 / 布局 | `profile_dir/` 下的配置文件 | 人可读，便于备份与进版本控制 |
| 会话日志 | 用户指定或默认目录 | 默认关闭；写入前做转义清洗 |

`profile_dir` 由 `term-paths` 决定，可用 `WINDTERM_PROFILE_DIR` 覆盖。

## 网络面

- 程序只主动连接用户配置的主机（SSH / Telnet / SFTP / 隧道目标）与本地
  回环上的自建服务（`term-desk serve`）。
- 没有遥测上报，也没有自动更新外联；网络活动面板把程序自身的连接列出来，
  便于核对。
- `term-desk serve` 默认只监听 `127.0.0.1`，连接的第一条请求必须完成 token
  握手。

## 报告问题

发现安全问题时，请通过仓库的 **Security → Report a vulnerability** 私密通道
提交，不要在公开 issue 里贴可利用细节。
