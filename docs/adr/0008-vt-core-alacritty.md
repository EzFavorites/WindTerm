# ADR-0008 · VT 解析下沉到进程内，渲染用自研 egui 网格

- 状态：已采纳（取代 ADR-0003）

## 背景

ADR-0003 的前提是「VT 解析放在前端的 xterm.js」。改用 egui 之后（ADR-0007），这个前提消失：进程内没有任何终端仿真器。

`portable-pty` 只提供 PTY 句柄与字节流，它不是终端。从 PTY 读到的数据形如 `ESC[1;32mfoo ESC[0m`，要变成画面需要三样东西：

1. 解析器：把 ANSI / VT 转义序列翻译成语义动作（SGR、光标移动、滚动区域、交替屏幕、鼠标模式等）；
2. 屏幕模型：单元格网格、回看缓冲、宽字符占位、属性继承、重排；
3. 渲染器：把网格画到绘制层的画布上。

缺任何一环，PTY 的输出就只是乱码。

## 决策

- 解析器与屏幕模型：采用 `alacritty_terminal`（Apache-2.0，含 `Term`、`Grid`、`Selection`、`VteListener` 全套）。
- 渲染器：自研 egui 控件 `TermView`，基于逐行字形缓存加脏区重绘。
- 不单独引进解析器库 `vte`：它只有解析器、没有屏幕模型，单用它等于把上游的一半工作接过来自己写；只有屏幕模型本身就要自研时，解析器层退回到 `vte` 才划算（见「后续演进」）。

### 理由

- **成熟度**：`alacritty_terminal` 是现成最完整的 Rust VT 实现，宽字符、重排、交替屏幕、滚动区域、鼠标模式都已覆盖。自研解析器的问题不是写不出来，而是兼容性长尾没有尽头。
- **许可干净**：Apache-2.0，与自有代码一致。相比之下 GNOME 的 VTE 是 LGPL，Qt 的终端组件同理，都会带来链接义务。
- **同栈同进程**：`Term` 是纯数据结构，可以在 IO 侧解析、在 UI 侧读快照，不需要 IPC 序列化。这是 egui 路线相对 Tauri 的一个实际红利。

### 关键设计：解析与渲染的边界

```
PTY / SSH 字节流
   │
   ├─► 解析器（VteListener::advance）
   │        └─ 持有网格、回看、SGR 状态、光标、选区
   │
   └─► 脏区标记（行位图 / 行版本号）
            │
            ▼
       UI 侧每帧读取可视区域的行快照
            │
            ├─ 每行一个字形缓存（按属性分段，键为行内容哈希加宽度）
            ├─ 宽字符：占两列，第二列写占位
            └─ 光标、选区、下划线、反显：按单元格矩形叠加绘制
```

三条硬约束：

1. **UI 线程不做解析，解析线程不做绘制**。终端状态由 IO 侧单写，UI 侧只读；锁的粒度按行切分，而不是锁住整个终端状态，否则高帧率下会争锁。
2. **每行字形必须缓存**。逐单元格调用文本绘制在 200×60 网格下会掉到不可用的帧率；按行缓存后，静态内容几乎零成本。
3. **脏区驱动重绘**，不要无条件请求重绘。空闲终端应当接近零 CPU。

## 后果

正面：

- 解析器的正确性直接继承上游实现与其测试。
- 语义能力全部在进程内、可跨会话：搜索、命令块识别、审计、冷热分层回看都不再受前端缓冲区容量限制——ADR-0003 里「无法实现无限回看」的退让就此撤销。
- 大吞吐下的性能上限由自己控制，可以做批量解析与合并重绘。

负面：

| 负面 | 处理 |
|---|---|
| 上游是 0.x，API 不承诺跨版本稳定 | 锁定精确版本；封装内部适配层，升级只改适配层 |
| 上游面向其自身终端需求，部分扩展协议不支持 | 记录为已知限制，需要时在适配层外挂 |
| 自研渲染器的工程量（见 ADR-0007） | 作为单一核心目标排期，不并行 |
| 上游的重排行为与预期可能不同 | 用固定字节流到固定网格快照的金样本回归锁住行为 |

后续演进：ADR-0009 把解析器迁移整体推迟为独立排期，先落地自研屏幕模型——转义序列的解析交给 `vte` 的状态机，语义动作由自写处理器完成。本 ADR 中「解析在进程内、UI 只读快照、脏区驱动重绘」的边界与后果不变，变的只是解析器这一层的实现，这也是适配层必须从第一天就存在的原因。

## 备选方案与否决理由

| 方案 | 否决理由 |
|---|---|
| 自研 VT 解析器 | 起步成本高，且兼容性长尾需要长期积累，不是一次能写完的工作 |
| `vte` 解析器单独使用 | 只有解析器，屏幕模型仍要自研，等于重做上游一半 |
| `wezterm-term` | 未在 crates.io 常规发布，供应链风险高于 `alacritty_terminal` |
| `vt100` | 功能过窄，无回看、交替屏幕、鼠标模式，只适合极简终端 |
| 回退到前端终端组件（ADR-0003） | 与 ADR-0007 冲突 |
