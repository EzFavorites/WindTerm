# 使用说明

本文只写当前实现确实具备的能力。界面细节会随版本变化，以应用内为准。

## 首次启动

1. 从 Releases 下载对应平台的包，解压。
2. macOS：首次启动被 Gatekeeper 拦下时右键 → *打开*，或执行
   `xattr -dr com.apple.quarantine WindTerm.app`。
3. 首次启动会在平台配置目录下建立应用子目录，存放会话库、偏好与布局。

数据目录可以用 `WINDTERM_PROFILE_DIR` 整体重定向（便携配置、测试隔离都靠它）：

```sh
WINDTERM_PROFILE_DIR=/tmp/wt-profile ./windterm
```

## 会话

- 新建会话时选择连接类型：**SSH**、**Telnet**、**Serial**、**本地 Shell**，
  或独立的 **SFTP** 会话。
- 会话树支持分组、重命名、拖拽排序与过滤；树结构随会话库持久化。
- 可以从 MobaXterm 导出的会话文件批量导入（树结构还原，重复项按
  `name + host + port` 去重）。

### SSH

- 认证方式：密码、私钥、ssh-agent。密码有三种保存策略：不记住 / 本次记住
  （只在内存）/ 永久记住（写入保险库，需要主密码）。
- 主机密钥采用 TOFU：首次连接时记录指纹到 `known_hosts`；之后指纹变化会
  **阻断连接**并同时列出新旧指纹，需要在设置里显式「忘记」该主机才能重连。
- 跳板机：会话属性里可以指定另一台会话作为跳板，最多 5 跳；同一条跳板链会
  复用已有连接，不重复登录。
- 网络面板会列出程序自身发起的连接，便于核对。

### 终端

- 多标签、左右/上下分屏与四宫格分屏。
- 查找、字号缩放、回滚行数、配色方案（内置多套，可导入 Windows Terminal 的
  `schemes` JSON 与 iTerm2 的 `.itermcolors`）。
- 编码切换（UTF-8 / GBK / GB18030 / Big5 / Shift-JIS / Latin-1）：只影响切换
  之后的输出，已显示内容不重排。
- 选中即复制、多行粘贴确认、bracketed paste、鼠标上报。
- 多执行广播：同一条命令发给多个会话，输出按一致性分组；危险命令强制确认。

### SFTP 与文件

- 文件面板顶部可切换「对着哪台机器」，每台各自记住浏览位置。
- 浏览、双击进入目录、下载、上传（拖拽即上传）、新建目录/文件、重命名、
  删除、改权限、查看/修改时间。
- 远端文件编辑：下载到本地、用系统程序打开、保存后写回；写回是原子的，
  并保留原文件权限位。
- 内嵌文本编辑器：多标签、行号、查找替换（可正则）、按扩展名着色、编码与
  换行符识别和切换、大文件保护。

### 隧道

- `-L` 本地转发、`-R` 远程转发、`-D` 动态 SOCKS5 代理（CONNECT-only，可选
  用户名密码认证）。
- 每条隧道显示双向字节计数与最近错误；`port=0` 时回填服务端分配的端口。
- 隧道配置可以落库并在保险库解锁后自动拉起；可导出/导入 JSON（导出不含口令）。

## 设置与键位

设置中心覆盖常规、外观、终端、文件、安全、网络、高级七组。每项标注生效范围、
默认值和是否需要重启。

键位可以逐动作重绑、导出/导入方案、恢复默认。重复的键位会被拒绝并说明被谁
占用；`Ctrl+C` 始终作为 SIGINT 发给远端，不参与重绑。

命令面板（搜索框）把动作、工具、会话、隧道、设置项拉平到一处检索。

## 脚本

`term-desk script run file.rhai` 在独立会话里执行脚本。脚本引擎在
[`scripting.md`](scripting.md) 里说明。

无窗口子命令适合排障与自动化：

```sh
term-desk doctor          # 环境体检
term-desk capability      # 能力面统计
term-desk --version
```

## 常见问题

**连不上，提示主机密钥变化？** 这是 TOFU 的保护：服务端换了密钥或被中间人
替换。确认服务端指纹无误后，在设置 → 安全 → 已知主机里删除对应记录再连。

**密码框自动填入的密码被拒？** 保险库里的旧口令可能已过期；重新输入并保存
会覆盖。

**中文显示成乱码？** 在底栏切换编码（GBK / GB18030）；切换只影响之后的输出。

**macOS 首次启动打不开？** 见「首次启动」的 Gatekeeper 说明。
