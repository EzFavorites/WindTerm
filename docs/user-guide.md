# 使用说明

本文只写当前实现确实具备的能力。界面细节会随版本变化，以应用内为准。

## 首次启动

1. 从 Releases 下载对应平台的包，解压。
2. macOS：首次启动被 Gatekeeper 拦下时右键 → *打开*，或执行
   `xattr -dr com.apple.quarantine WindTerm.app`。
3. 首次启动会在平台配置目录下建立应用子目录，存放会话库、偏好与布局。

数据目录可以用 `WINDTERM_PROFILE_DIR` 整体重定向（便携配置、测试隔离都靠它）：

```sh
WINDTERM_PROFILE_DIR=/tmp/wt-profile ./windterm
```

## 会话

- 新建会话时选择连接类型：**SSH**、**Telnet**、**TCP**、**Serial**、**本地
  Shell**，或独立的 **SFTP** 会话。
- 会话树支持分组、重命名、拖拽排序与过滤；树结构随会话库持久化。
- 可以从 MobaXterm 导出的会话文件批量导入（树结构还原，重复项按
  `name + host + port` 去重）。导入只带配置不带密码——密码永不迁移。
- 模型上是**会话为单元、标签为投影**：分屏时每个窗格各自持有一组标签，
  标签只是会话在某个窗格上的一个视角。

### SSH

- 两种客户端，按会话选：**内置 SSH**（进程内实现，SFTP、隧道、跳板链都建立在
  它之上，且能自动注入保险库口令）与**系统 `ssh`**（拉起系统程序，直接复用
  `~/.ssh/config` 与 agent）。新建 SSH 会话默认走内置；从更早版本升级上来的旧
  会话继续用系统 `ssh`，会话属性里可以切换。
- 认证方式：密码、私钥、ssh-agent。密码有三种保存策略：不记住 / 本次记住
  （只在内存）/ 永久记住（写入保险库，需要主密码）。
- **OneKey 登录方案**：会话表单里有一行 `OneKey:`，从已保存的方案里选一个，
  也可以点行内齿轮直接编辑方案。方案是可复用的认证配置单元（用户名、当前系统
  要用的私钥等），改一条方案，所有引用它的会话下次连接都跟着变。
- 方案的边界：它能带进**用户名与私钥**（系统 `ssh` 会拼成 `-l` / `-i`），但
  带不进**密码**——OpenSSH 不接受从命令行喂密码。所以系统 `ssh` 的密码必须手
  敲；内置 SSH 才会按"方案 → 保险库 → 弹框"的顺序补上。
- 主机密钥采用 TOFU：首次连接时记录指纹到 `known_hosts`；之后指纹变化会
  **阻断连接**并同时列出新旧指纹，需要在设置里显式「忘记」该主机才能重连。
- 跳板机：会话属性里的 ProxyJump 是逗号分隔的跳列表（`[user@]host[:port]`）。
  每跳都是一次完整的握手与认证，只有第一段是 TCP，之后每段是上一条连接里的
  通道；某跳没写用户名就沿用目标会话的用户名。每跳按自己的主机记账
  `known_hosts`；agent 转发只作用于最终目标。
- 网络面板会列出程序自身发起的连接，便于核对。

### 终端

- 多标签、左右/上下分屏与四宫格分屏。
- 查找、字号缩放、回滚行数、配色方案（内置多套，可导入 Windows Terminal 的
  `schemes` JSON 与 iTerm2 的 `.itermcolors`）。
- 编码切换（UTF-8 / GBK / GB2312 / Big5 / Shift_JIS / EUC-JP / EUC-KR /
  KOI8-R / ISO-8859-1 / ISO-8859-15）：只影响切换之后的输出，已显示内容不重排。
- 选中即复制、多行粘贴确认、bracketed paste、鼠标上报。
- 多执行广播：同一条命令发给多个会话，输出按一致性分组；危险命令强制确认。
- **tmux 控制模式**：`Window › Panes › Tmux Control Mode` 打开。对已进入
  `tmux -CC` 的会话，**解析并展示**远端的 tmux 状态（窗口号、窗格号、布局、
  命令块），并可在面板里向选中的窗格/窗口下发经过目标校验的反向控制命令；
  **不把 tmux 的窗口/面板映射成本地标签与分屏**（见 `docs/design/08-tmux-integration.md`
  的「只记录、不重排」口径）。解析失败的指令一律原样透传，不会破坏远端状态。
- **会话日志**：`Session › Log` 里起停、暂停/恢复、打开日志文件或目录、改
  日志设置。默认记录清洗后的可打印文本；可选记录全部原始字节。暂停会在日志里
  留一行标记说明停了多久，恢复后继续写；同名文件默认加序号而不是覆盖。
  `Mode › Debug Mode` 在画属性覆盖层之外，还会在日志槽空闲时起一份 `debug_` 前缀
  的原始字节排障日志（含转义序列，16 MiB 后自动轮转），失败会在状态栏报出；
  已有会话日志时不抢占那个唯一槽位。

### SFTP 与文件

- 文件面板顶部可切换「对着哪台机器」，每台各自记住浏览位置。
- 浏览、双击进入目录、下载、上传（拖拽即上传）、新建目录/文件、重命名、
  删除、改权限、查看修改日期。
- 远端文件编辑：下载到本地、用系统程序打开、保存后写回；写回是原子的，
  并保留原文件权限位。
- 文件编辑不内建通用编辑器：远端文件先下载到本地，用系统程序打开，保存后
  原子写回并保留权限位；另提供只读的开头预览窗（不跟随文件变化）。
- **文件预览**：在文件面板双击一个文件（或右键「预览」）直接开预览窗。本地
  文件立刻读开头；远端文件先自动下载到临时目录再开窗。预览只读文件开头（大
  文件不会整个读进内存），按字节内容判断类型而不是扩展名；图片显示占位框与
  尺寸，文本显示开头若干行。预览是快照，不跟随文件变化。
- **X / Y / ZMODEM**：`Tool` 菜单里的 Send / Receive 六项。传输走原始字节
  旁路：传输期间屏幕冻结是正常的，进度在传输面板；取消时"停下方式"决定目标
  文件是删除还是保留半截。

### 隧道

- `-L` 本地转发、`-R` 远程转发、`-D` 动态 SOCKS5 代理（本地监听器当前只支持无认证客户端；出网代理的凭据在连接配置里设置）。
- 每条隧道有名字与归属会话；面板显示运行状态，起不来或中断的条目原样给出
  失败原因，而不是静默消失。
- 监听端口必须显式指定：动态分配（端口填 0）在表单这一层就被拒绝——系统挑
  的端口用户没法知道，与其点完确认再报错，不如当时就说清。
- 配置随偏好落库；总开关之外每条还有「自动启动」勾选，勾上的条目在应用启动
  且总开关打开时自动拉起。关掉总开关会清空已起的隧道。
- 隧道用**独立的 SSH 连接**搬运字节，不复用终端那条：两种通道形状不同，独立
  连接的代价是第二次认证——凭据已在内存里，不会再次询问。

## 设置

设置中心（`Session ▸ Preferences ▸ Settings`）默认停在 **Application** 页，
左栏树覆盖：应用、外观、代理、在线搜索、安全、标签、终端（自动补全 / 命令
历史 / 鼠标上报）、文本（二进制 / 光标 / 字体 / 高亮 / 折行）、挂件、文件
面板、快捷栏、触发器、OneKeys 凭据管理器。

- 大多数页面改的是**默认参数**：只对新开的会话生效，已开的标签不追溯；
  相关页面底部有说明，避免"改完没反应"被当成控件坏了。
- 触发器规则（事件 → 匹配 → 动作）与 OneKeys 凭据管理器（SSH / Account /
  Sessions 三标签）由 `Terminal › Manage Triggers` / `Manage OneKeys` 直接
  打开，编辑结果立即写回偏好并在后续连接中生效。
- 改完立即生效，不需要重启应用。

命令面板（搜索框）把动作与菜单项拉平到一处检索，分两种模式：**Command**
只列已接线的命令、选中即执行；**Anything** 列出全部菜单项并标注哪些尚未
接线。检索按标签与标识做子串匹配，空查询时给出最近使用与常用分组。

## 脚本

`term-desk script run file.rhai` 在独立会话里执行脚本。脚本引擎在
[`scripting.md`](scripting.md) 里说明。

无窗口子命令适合排障与自动化：

```sh
term-desk doctor          # 环境体检
term-desk capability      # 能力面统计
term-desk serve --port 0  # 把能力面暴露到 127.0.0.1（需 token 文件）
term-desk --version
```

`serve` 只监听回环地址；连接后的第一条请求必须完成 token 握手，锁屏时返回
`Locked` 错误而不是数据。脚本与桥接共用同一张能力面动词表（详见
[`scripting.md`](scripting.md)）。

## 常见问题

**连不上，提示主机密钥变化？** 这是 TOFU 的保护：服务端换了密钥或被中间人
替换。确认服务端指纹无误后，在设置 → 安全 → 已知主机里删除对应记录再连。

**密码框自动填入的密码被拒？** 保险库里的旧口令可能已过期；重新输入并保存
会覆盖。

**中文显示成乱码？** 在会话属性里切换字符集（GBK / GB2312 / Big5 等）；切换
只影响之后的输出，已显示内容不重排。

**macOS 首次启动打不开？** 见「首次启动」的 Gatekeeper 说明。
